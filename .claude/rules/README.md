# Temporary project notes for cloud sessions

The rest of this directory is a snapshot of project knowledge that normally
lives in this user's local Claude Code memory (`~/.claude/projects/.../memory/`)
on one specific machine — which doesn't sync to cloud/web sessions on other
devices. These files exist so a cloud session has that context too.

**Treat these as point-in-time notes, not live state.** Each carries the date
it was last touched; verify anything load-bearing against the actual code,
git history, or a live check before treating it as current fact — the same
caution the local memory system itself asks for.

**Not included here, deliberately:**
- Demo account credentials (a real, working password for accounts in the live
  production database — this repo is public, so that stays local-only)
- Notes about this specific machine's local git workflow (concurrent local
  sessions, auto-commit behaviour) — not relevant to a cloud session running
  in its own isolated environment

This directory is meant to be temporary. Once cloud access isn't needed, or
once anything worth keeping long-term has been folded into `CLAUDE.md`
proper, delete it.
